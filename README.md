# About Me

Basically, I made an About Me website.

Then I thought, "why make it normal?"

So yeah, this happened.

This is my personal website where I put some stuff about me, my projects, things I've built, things I'm working on, and whatever else I feel like putting there.

It's not supposed to be some super serious corporate portfolio.

It's just me.

## So, who am I?

I'm **yourr-ikyy**.

I like making websites, messing around with UI, building random projects, experimenting with stuff I probably didn't need to experiment with, and turning random ideas into actual projects.

I use:

* HTML
* CSS
* JavaScript
* Lua
* Arduino
* UI/UX
* And basically whatever I need for the thing I'm currently building

Sometimes I start with:

> "This should be simple."

And then, somehow, there's 700 lines of CSS.

## Why Frutiger Aero?

Because I like it.

That's basically the reason.

I wanted this website to feel colorful, nostalgic, glossy, slightly ridiculous, and actually fun to look at.

So instead of making another dark developer portfolio with a terminal and a bunch of glowing cards, I went with blue skies, clouds, green hills, water, bubbles, glassy UI, and way too many visual effects.

And honestly?

I'd do it again.

## What's on the website?

A bunch of things.

There's my introduction, projects, skills, social links, some interactive stuff, animations, and probably a few details you won't notice immediately.

I wanted the website to feel more like an actual little place on the internet rather than just a page that says:

> "Hello. I am a developer. Here are my skills."

Because that's boring.
